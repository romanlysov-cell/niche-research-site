# niche-research-site

Public website for **Niche Research** — a market research tool that analyzes
publicly available marketplace and web data to identify trends, pricing patterns,
customer needs, and opportunities for digital products.

Hosted on GitHub Pages at [aragorn.space](https://aragorn.space).

## Files

- `index.html` — landing page
- `privacy.html` — privacy policy
- `terms.html` — terms of use

Static HTML/CSS only: no frameworks, no trackers, no analytics.

Niche Research is an independent research tool and is not affiliated with Etsy.
