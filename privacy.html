Privacy Policy

Last updated: February 2026

1. What this website is

This website describes Niche Research, a market research tool that analyzes publicly available marketplace and web data. The website itself is a static informational page.

2. Data collected by this website

This website does not use cookies, analytics, trackers, or advertising services. It does not include contact forms or account registration, and it does not collect or store personal data from visitors. Like any static hosting, the hosting provider (GitHub Pages) may process standard technical logs (such as IP addresses) to deliver the pages; this is governed by GitHub's own privacy practices.

3. Data processed by the Niche Research tool

The research tool works only with publicly available data, such as:

  • public marketplace listings and categories;
  • public pricing information;
  • public search interest signals;
  • publicly available customer discussions and reviews.

The tool is not designed to access, modify, or store private data of users or sellers. It does not process private messages, non-public account information, or any data that is not openly published.

4. Third-party platforms

Public data analyzed by the tool originates from third-party platforms. Those platforms have their own privacy policies, which apply to the data they publish. Niche Research is an independent research tool and is not affiliated with Etsy.

5. Changes to this policy

If the way the website or the tool handles data changes, this page will be updated. The current version is always available at this address.

6. Contact

Questions about this policy can be raised via the project's GitHub repository.
